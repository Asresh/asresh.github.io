01. RTL Design

Clean, synthesizable SystemVerilog — one self-contained, self-checking digital block a day. Every design ships with a golden-reference scoreboard and a Makefile flow for Icarus, Verilator, VCS and Questa, from CDC-safe FIFOs and IEEE-754 arithmetic all the way up to GPU/SIMT microarchitecture.

Featured Build

GPU Warp Scheduler + Register Scoreboard

An NVIDIA-class SM issue front-end. A per-warp register scoreboard tracks in-flight RAW/WAW hazards and gates each warp's readiness, while a greedy-then-oldest arbiter picks one ready warp to issue every cycle — staying with the current warp until it stalls, then falling back to the oldest. One deadlock-free instruction issue per clock, across the whole warp pool.

03. Hardware–Software Co-Design

Full-stack accelerators. Each build pairs parameterized SystemVerilog RTL with a real bus, working bare-metal C firmware that configures and drives it, and a differential testbench that proves the hardware bit-exact against a C golden model — then measures the cycle-count speedup over a scalar baseline. Continuous integration runs the whole thing under Icarus on every push.

Featured Build

Reorder Buffer — Precise Out-of-Order

The machinery behind precise out-of-order execution. Instructions allocate in program order at the tail, complete out of order on any entry as results land, and retire in order from the head — gated on done — so architectural state stays exact. Entry tags double as rename handles, circular head/tail pointers carry a wrap bit, and a single-cycle flush squashes the wrong path on a mispredict.
